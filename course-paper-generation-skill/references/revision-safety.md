# Revision Safety

- Treat the newest user-edited file as authoritative.
- Before revising an existing deliverable, create a versioned copy.
- Preserve user wording when the request is layout, format, chart, or export focused.
- Do not delete appendices, references, figures, or notes unless the user asks.
- Track what changed in `planning/revision-log.md`.
- Keep generated intermediate figures and scripts so later revisions can be reproduced.
