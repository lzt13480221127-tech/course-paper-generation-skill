# Paper Structures

## Course Paper

Use for theory-heavy or literature-supported assignments.

1. Title
2. Abstract and keywords
3. Introduction
4. Literature review or theoretical basis
5. Main analysis
6. Discussion
7. Conclusion
8. References

## Case Study

Use when the assignment centers on a company, region, product, management issue, or practical problem.

1. Case background
2. Problem definition
3. Analytical framework
4. Data or evidence
5. Diagnosis
6. Solution design
7. Implementation risk
8. Conclusion

## Algorithm Experiment Paper

Use when the deliverable includes models, algorithms, computation, simulation, or optimization.

1. Problem background
2. Model assumptions and notation
3. Algorithm design
4. Data and parameter setting
5. Experiment results
6. Comparative analysis
7. Sensitivity or limitation discussion
8. Conclusion

## Data Analysis Report

Use when the assignment is driven by statistical or empirical analysis.

1. Research question
2. Data source and preprocessing
3. Variable definition
4. Method
5. Results
6. Robustness or limitation
7. Conclusion
