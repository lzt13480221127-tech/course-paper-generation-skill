# Figures And Tables

## Figure Rules

- Every figure needs a clear caption and a reason to exist.
- Use Chinese labels for Chinese papers.
- Prefer editable charts when the target format supports them; otherwise export high-resolution PNG/PDF pairs.
- Keep chart colors restrained and distinguishable in grayscale when possible.
- Show units in axis labels.
- Keep source data or generation code in the workspace.

## Table Rules

- Use tables for exact values and comparisons.
- Use charts for trends, distributions, routes, relationships, and rankings.
- Align numbers consistently.
- Include notes for assumptions, units, or data filters.

## Algorithm Results

For algorithm papers, include:

- dataset or case description
- assumptions and constraints
- parameter setting
- baseline methods
- runtime and quality metrics
- interpretation of why the result changes
